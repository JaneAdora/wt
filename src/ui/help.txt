wt :: Worktree Wizard

NAVIGATION
  ↑ ↓  or  j k       Move selection in focused pane
  Tab / Shift-Tab     Switch focus between WORKTREES and SESSIONS
  Enter               Project row: expand/collapse
                      Worktree row: focus the sessions pane
  e  or  E            Expand all / collapse all (toggle)

ACTIONS
  c                   Copy launch command to clipboard (OSC 52)
  o                   Print launch command to stdout and exit
  d  or  D            Print + exit with --dangerously-skip-permissions
                      (the "do it" key; assumes you've reviewed)

LAUNCH COMMAND SHAPE
  Worktree selected:  cd PATH && claude [--dangerously-skip-permissions]
  Interactive sess:   cd PATH && claude --resume ID [--dangerously-skip-permissions]
  Background job:     cd PATH && claude [--dangerously-skip-permissions]
                      (--resume isn't meaningful from outside the harness)

VIEWS
  r                   Refresh (preserves selection, filter, search, expansion)
  /                   Filter; type substring, Enter to apply, Esc to cancel
  a                   Toggle active-only filter (default on)
  t                   Cycle interactive-session window: 30d > all > 7d
  g                   Show commit log for the selected worktree
  ?                   Show this help

DELETE
  x                   Delete the selected background job (state.json + dir).
                      Two-press confirm: first press arms, second within
                      3s deletes. Refuses while job is Running.

EXIT
  q  or  Ctrl-C       Quit

IN A MODAL (log or help)
  j k  or  ↑ ↓        Scroll one line
  Space / PgDn        Page down
  b / PgUp            Page up
  g / Home            Jump to top
  G / End             Jump to bottom
  Esc / q / Enter     Close modal

DISCOVERY SCOPE
  By default, wt scans:
    ~/projects/
    ~/Projects/
    ~/Projects/clients/
  Override with WT_ROOTS env var, colon-separated (like PATH):
    WT_ROOTS=~/projects:~/Projects:~/code wt

PERSISTENT STATE
  UI preferences (filter, expansion set, search, selection, time window)
  are saved to ~/.config/wt/state.json on quit and restored on launch.

ABOUT
  Single-host dashboard. Built for one terminal tab, designed for mobile
  SSH (Blink, Termius) via OSC 52 clipboard and width-collapsing.
