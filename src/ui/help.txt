wt :: Worktree Wizard

THE LAYOUT
  The screen has two panes stacked vertically:
    WORKTREES (top)  : your projects and their worktrees
    SESSIONS  (bot)  : Claude sessions attached to the selected worktree
  The focused pane has a bright pink border and a magenta title.

SWITCHING PANES
  1                   Focus the WORKTREES pane
  2                   Focus the SESSIONS pane
  Tab  /  Shift-Tab   Cycle focus between the two panes
                      (Both directions are the same when there are 2 panes.
                      Use 1 / 2 if Tab is awkward on your terminal.)

NAVIGATION (within the focused pane)
  ↑ ↓  or  j k       Move selection up/down
  ← →  or  h l       Tree navigation (worktrees pane):
                        Right on collapsed project: expand
                        Right on expanded project:  step into first worktree
                        Right on worktree row:      focus the SESSIONS pane
                        Left  on expanded project:  collapse
                        Left  on worktree row:      jump up to parent project
  Enter               Project row: expand/collapse
                      Worktree row: focus the SESSIONS pane
  e  or  E            Expand all / collapse all (toggle). Aliases.

ACTIONS
  c                   Copy launch command to clipboard (OSC 52); stay open
  o                   Open: copy to clipboard AND print to terminal, then exit.
                      Use this when you're ready to actually launch.
  d  or  D            Same as o, plus appends --dangerously-skip-permissions.
                      Aliases (lowercase / uppercase are the same key; bound
                      both so speech-to-text and caps-lock don't trip you up).

LAUNCH COMMAND SHAPE
  Worktree selected:  cd PATH && claude
  Interactive sess:   cd PATH && claude --resume ID
  Background job:     cd PATH && claude
  (Append --dangerously-skip-permissions when using `d` instead of `o`/`c`.)

VIEWS
  r                   Refresh (preserves selection, filter, search, expansion)
  /                   Filter by substring; type, Enter to apply, Esc to cancel
  a                   Toggle active-only filter (default on)
  t  or  T            Cycle interactive-session window: 30d > all > 7d. Aliases.
  g                   Show commit log for the selected worktree
  ?                   Show this help

DELETE
  x  or  X            Delete the selected background job (state.json + dir).
                      Two-press confirm: first press arms, second within
                      3 seconds deletes. Refuses while job is Running. Aliases.

EXIT
  q  or  Ctrl-C       Quit (saves UI state)

IN A MODAL (log or help)
  j k  or  ↑ ↓        Scroll one line
  Space / PgDn        Page down
  b / PgUp            Page up
  g / Home            Jump to top
  G / End             Jump to bottom
  Esc / q / Enter     Close modal

LEAVING SEARCH (the / mode)
  Esc                 Cancel; the filter clears
  Enter               Apply; the filter sticks until you press / again

DISCOVERY SCOPE
  By default, wt scans:
    ~/projects/
    ~/Projects/
    ~/Projects/clients/
  Override with WT_ROOTS env var, colon-separated (like PATH):
    WT_ROOTS=~/projects:~/Projects:~/code wt

PERSISTENT STATE
  UI preferences (filter, expansion set, search, selection, time window)
  are saved to ~/.config/wt/state.json on quit and restored on launch.

ABOUT
  Single-host dashboard. Built for one terminal tab, designed for mobile
  SSH (Blink, Termius) via OSC 52 clipboard and width-collapsing.
